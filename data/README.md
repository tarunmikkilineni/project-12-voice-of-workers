# Project 12 data

These CSV files contain the ratings and page-cited evidence used in **Worker Voice in Platform Governance**. The analysis draws on the public 2023 and 2025 Fairwork Cloudwork Ratings reports. The [source manifest](source_manifest.csv) gives the original PDF links and SHA-256 checksums.

| File | Records | Contents |
| --- | ---: | --- |
| [Extracted platform ratings](report_extracted_ratings.csv) | 31 | Platform–edition records with Fairwork awards and source pages |
| [Appeal change ledger](S2_appeal_change_ledger.csv) | 9 | RQ1 features from the 2025 change log |
| [Decision evidence ledger](S6_decision_evidence_ledger.csv) | 17 | RQ2 evidence records by platform, decision, and feature |
| [Worker-account coding](worker_account_coding.csv) | 6 | RQ3 selected observations, reported barriers, and alignment with cited procedures |
| [Recognition evidence ledger](S12_recognition_evidence_ledger.csv) | 7 | RQ4 documented public statements on organizing rights and explicit bargaining references |
| [Source manifest](source_manifest.csv) | 2 | Report filenames, URLs, page counts, and checksums |

These files are copies of the data exported by the [executed notebook](../project-12-voice-of-workers.ipynb). See the [evidence audit](../Results/evidence_source_audit.csv) for coding decisions and corrections. Independent recoding and adjudication are pending. The worker accounts are selected observations from published reports.
